1. Executive Summary
Arcasys: Marketing Archive Manager is a centralized, web-based event management and archiving system designed for Cebu Institute of Technology – University. It consolidates scattered event postings from social media, email, and print into one accessible platform, ensuring students, faculty, and marketing executives can easily access organized and reliable event information. The system features centralized event archiving, categorized into past, upcoming, and department-based events, with fast search and filtering tools (such as year, department, platform, and keywords). It offers role-based access for administrators, organizers, and viewers, along with notifications for new or updated events, and integration with external platforms like Facebook, Instagram, and YouTube. Built on Python with the Django framework for secure and scalable backend development, React.js is used for dynamic and responsive front-end interfaces, while MySQL stores and manages event data. Hosted on secure cloud infrastructure, the system ensures reliability and scalability. Arcasys improves efficiency by reducing duplication and delays in event communication, enhances transparency with an organized archive accessible anytime, and boosts user satisfaction through clear and accurate information. With a strong foundation for future enhancements, it also supports scalability for potential mobile app integration and AI-driven event recommendations.






2. Background / Problem Statement
Cebu Institute of Technology – University currently uses decentralized methods for managing and disseminating event information — via social media, emails, and printed materials. This fragmentation leads to problems like difficulty in retrieving event links, lack of tracking of event history, and confusion between past vs. upcoming events.
Research highlights that this kind of decentralization causes inefficiencies and communication gaps in higher education. The Modernizing Event Management in Higher Education study notes that many campuses rely on “disparate systems or have no system at all” for managing events — leading to partial results and poor coordination among departments (Momentus, 2024).
Additionally, the CU-Events case study shows how a centralized event management platform tailored to a university’s needs can increase user engagement, improve administrative efficiency, and simplify real-time tracking and reporting (Chaturvedi, Sharma, Dua, & Gupta, 2024).
Another recent work, A Survey on Centralized Event Management System (CEMS), confirms that in educational institutions, centralizing event coordination helps reduce manual administrative effort and enhances collaboration among organizers, thereby improving both accessibility and overall efficiency (A Survey on CEMS, 2025).
Hence, there exists a strong opportunity for CIT-U to adopt a centralized event archiving and management system to address these issues, improve access, reduce redundancies, and enhance institutional coordination.

5. Methodology / Approach
The development of Arcasys: Marketing Archive Manager will follow an Agile methodology with eight structured sprints. Each sprint builds on the previous one, ensuring continuous improvement and stakeholder feedback throughout the process.


Sprint 1 – Design & Prototyping (Part 1) (Oct 3, 2025, 2 weeks)


Create initial UI/UX wireframes for event pages, search interface, and admin dashboard.
Develop database schema and workflow diagrams.


Sprint 2 – Design & Prototyping (Part 2) (Oct 17, 2025, 2 weeks)


Refine mockups based on feedback from Marketing Executives and faculty.
Finalize responsive design to ensure usability across devices.


Sprint 3 – Development (Core Features) (Oct 31, 2025, 2 weeks)


Implement backend functions in Django with MySQL database integration.
Develop core features: event CRUD operations, search/filter engine, and categorization.


Sprint 4 – Development (Integration & Enhancements) (Nov 14, 2025, 2 weeks)


Add notifications for event updates and cross-platform integration (FB, IG, YT).
Implement role-based access control and admin dashboard.


Sprint 5 – Testing & QA (Nov 28, 2025, 2 weeks)


Perform unit and integration testing.
Conduct UAT with at least 50 Marketing Executives and students.
Ensure system achieves ≥90% user satisfaction before launch.


Sprint 6 – Deployment & Closure (Dec 12, 2025, 2 weeks)


Deploy system on secure cloud hosting.
Conduct training sessions and awareness campaigns to drive adoption.
Finalize technical documentation and system handover.
